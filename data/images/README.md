# Dataset Data

This directory contains the image data used in the Everyday Object Detection project.

## Directory Structure

```text
data/
└── images/
    └── train/
        ├── image_001.jpg
        ├── image_002.jpg
        └── ...
```

## Dataset Details

- **Total training images:** 24
- **Image format:** JPG
- **Object classes:** cup, mobile_phone, bottle

The corresponding YOLO annotation files are stored separately in `labels/train/`.
