# Training Images

This folder contains the 24 image files used in the Everyday Object Detection dataset.

## Dataset Details

- **Total images:** 24
- **Image format:** JPG
- **Image split:** Training
- **Annotation format:** YOLO Detection

## Annotated Object Classes

The images contain examples of the following object categories:

- `cup`
- `mobile_phone`
- `bottle`

## Annotation Information

Each image has a corresponding YOLO-format annotation file stored in the `labels/train/` directory.

Image filenames are matched with their respective annotation filenames to maintain consistency.

## Purpose

These images were collected and organized to demonstrate practical object detection annotation skills using CVAT and the YOLO format.
